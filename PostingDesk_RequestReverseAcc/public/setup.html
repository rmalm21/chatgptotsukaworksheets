POSTING DESK / PANDUAN

Panduan penggunaan.

Ringkasan alur kerja Request Reverse dan Cancel Park untuk requester maupun pemosting.

Membuat request

  1. Pilih ruang Request Reverse atau Cancel Park, lalu pilih entitas AIO atau ODI.
  2. Tempel nomor dokumen. Sistem dapat membaca nomor, entitas, tahun, dan istilah singkat seperti rq rvs, rvs, cncl, cnle, atau park.
  3. Periksa preview lalu kirim. Enter mengirim request dan Shift+Enter membuat baris baru.

Requester dan tanggal request mengikuti akun serta input yang aktif. Catatan dapat ditambahkan melalui Detail request.

Antrean, Selesai, dan Arsip

Antrean selalu menampilkan seluruh pengajuan yang belum selesai untuk ruang dan entitas aktif, tanpa filter periode. Ini memastikan request lama yang masih terbuka tidak terlewat.

Selesai dan Arsip memiliki filter periode. Gunakan indeks bulan, preset tanggal, atau rentang khusus untuk melihat riwayat tanpa memuat data yang tidak diperlukan.

Sampah berisi request yang dihapus. Data yang masih memenuhi hak akses dapat dipulihkan.

Memproses dokumen

  • Pemosting dapat menandai satu atau beberapa dokumen sebagai Selesai.
  • Dokumen selesai dapat diarsipkan satu per satu atau secara bulk.
  • Buka kembali mengembalikan dokumen selesai ke Antrean.
  • Pulihkan mengembalikan dokumen dari Arsip atau Sampah sesuai status sebelumnya.

Memilih dan menyalin nomor

Gunakan checkbox untuk tindakan bulk. Tombol Copy menyalin nomor pada hasil Antrean. Di desktop, nomor dokumen juga dapat didrag ke bawah; hanya kolom nomor yang disorot dan kumpulan nomor tersebut langsung dicopy tanpa ikut mengambil Requester, tanggal, entitas, atau tahun.

Tampilan Ringkas cocok untuk daftar panjang, sedangkan Lengkap menampilkan konteks tambahan.

Edit dan hapus

Buka menu … pada dokumen untuk melihat detail. Requester dapat mengedit atau menghapus request Pending miliknya sendiri. Pemosting memiliki akses pengelolaan sesuai perannya.

Penghapusan bersifat soft-delete: dokumen masuk ke Sampah dan tidak langsung hilang permanen.

Ruang tim dan Request saya

Antrean tim menampilkan request seluruh anggota. Request saya membatasi daftar ke request yang dibuat oleh akun yang sedang login. Badge pada ruang dan entitas menunjukkan jumlah request yang masih terbuka.

Jika ada kendala

  • Pastikan koneksi internet aktif dan status sinkronisasi menunjukkan Tersambung.
  • Jika tindakan ditolak, pastikan status dokumen masih sesuai dan akun memiliki role yang benar.
  • Jika tampilan belum berubah setelah pembaruan aplikasi, lakukan hard refresh browser.
